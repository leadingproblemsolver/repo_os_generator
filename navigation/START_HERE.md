# Start Here

1. Read `README.md` for product and operating model.
2. Read `INDEX.md` to locate the owning context.
3. Read `ARCHITECTURE.md` for system boundaries.
4. Read `OPERABILITY.md` for commands and proof rules.
5. Run `make verify` to prove local health.
6. If you are junior or intern, read `navigation/JUNIOR_NAVIGATION_GUIDE_HI.md`.
7. Choose work from `execution/ACTIVE_WORK.md`.
